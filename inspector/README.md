# 광업제조업동향조사 내검 — 새 화면 개발판 0.1

`index.html`을 내려받아 Edge 또는 Chrome에서 여세요. 서버·설치·인터넷 연결은 제품 실행에 필요하지 않도록 구성했습니다. 단, 이 개발환경의 파일 직접 열기는 관리자 정책으로 차단되어 로컬 HTTP에서 브라우저 기능을 시험했습니다. 기관 PC에서 파일 직접 실행은 별도로 확인해야 합니다.

## 사용 순서

1. 명부·동태1·동태2·고용·능력 파일을 같은 등록창에 넣습니다. 자료 교체도 같은 창을 사용합니다.
2. 동태1에서 자동 확인한 조사월과 등록상태를 확인합니다. 동태2는 해당 조사표 대상일 때 등록합니다.
3. 내검 실행 후 확인사항을 선택해 수치근거·기준·원자료 위치를 확인합니다.
4. 확인결과를 입력하고 엑셀·CSV·JSON을 필요할 때 직접 저장합니다. CSV는 현재 필터, 엑셀은 전체 검토대상과 검사범위를 저장합니다.
5. 모든 자료 지우기 또는 탭 닫기로 메모리 자료를 제거합니다. 자동 복구·자동 저장은 제공하지 않습니다.

가상자료 시연 시작 → 내검 실행으로 사용할 수도 있습니다. 가상자료는 업무상 정확성 검증을 대신하지 않습니다.

## 구성과 범위

새 화면과 사용 흐름을 별도로 작성했습니다. 계산 모듈·회귀시험은 사용자가 제공한 v0.6.0 소스에서 재사용했습니다. 땡큐 VBA나 261020 HTML 코드를 새 코드로 옮긴 것은 아닙니다. 완전한 신규 계산엔진 또는 기존 기능의 전수 구현을 주장하지 않습니다.

- 통합 등록, 머리글 기반 자동 분류, 조사월 자동 확인
- 30개 규칙 등록과 상태별 조회·페이지 처리
- 수치근거·기준·원자료 위치·확인결과 메모
- Excel·CSV·JSON 저장
- 530개 품목의 검색용 추출문 검색 (원문 이미지 미포함)

보류/자료부족을 정상과 구분합니다. 중복 계상·수탁실적 대조·과거 확정자료 변경은 미실시 항목이 있습니다. 검증된 전체 품목사전과 조사 지침서·시스템 설명서의 원문 대조가 필요합니다. 가동률 등 기준 충돌은 업무 확인 전 기본값입니다. 재투입 대비 생산은 2차 삭제 의견과의 적용 관계가 미정입니다. 기존 전체 기능과의 대조 및 실제 조사자료 검증이 완료되지 않았습니다.

자료는 브라우저 메모리에서 처리합니다. 계산은 현재 메인 스레드에서 수행하므로 대용량 처리 성능 검증과 작업자 분리는 후속 과제입니다. 50MB 초과 파일은 등록하지 않습니다. 여러 후보 시트가 있는 파일은 임의 선택하지 않고 등록 진단으로 안내합니다.

## 개발과 검증

Node.js와 내장된 SheetJS CE 0.20.3을 사용합니다. vendor/LICENSE.txt를 유지합니다.

```sh
cd inspector
node build.mjs
node --test test/engine.test.mjs test/adapter.test.mjs test/baseline.test.mjs test/export.test.mjs
```

위 계산 회귀시험은 62개 통과했습니다. 기존 workflow 시험 10개 중 9개 통과, 1개는 별도 handbook-pages 원문 이미지 부재로 실패합니다. 원문 이미지를 사용하지 않는 이번 화면에서 원문 열기를 지원한다고 표시하지 않습니다.

`test/browser.cjs`는 Playwright가 있는 개발환경에서 로컬 HTTP로 브라우저 시연·등록·다운로드를 검증합니다. 실제 조사자료 시험과 보안·기관 환경 점검은 별도로 필요합니다.

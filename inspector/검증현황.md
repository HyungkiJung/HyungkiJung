# 개발판 0.1 검증 현황

- 빌드 성공.
- 계산·등록·출력 회귀시험 62개 통과.
- 기존 workflow 시험 10개 중 9개 통과, 원문 이미지 완전성 1개 실패(파일 누락).
- Playwright 로컬 HTTP 시험: 가상자료 등록, 내검, 근거 조회, 확인결과 메모, Excel 다운로드, 품목검색, 초기화, 생성 XLSX 5종 등록 후 재내검 통과.
- 다운로드된 Excel을 다시 읽어 확인결과 메모 보존 확인.
- file:// 실행은 관리자 정책 차단으로 검증 못함.
- 실제 조사파일 대조·기관 PC 시험·지침 원문 대조·보안 사전점검 미완료.
- 30개 규칙을 모두 등록한 것과 모든 기능을 검증 완료한 것은 다름. 보류와 자료 부족은 화면에 표시.
- 새 UI는 신규 작성, 계산 모듈 및 시험은 제공 v0.6.0 소스 재사용.
